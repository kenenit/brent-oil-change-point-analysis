# Notebooks

Exploratory and analysis notebooks for the Brent oil change point project.

| Notebook | Purpose |
|---|---|
| `01_eda.ipynb` | Data loading, cleaning, trend/stationarity/volatility analysis |
| `02_change_point_model.ipynb` | Bayesian change point model (PyMC), convergence diagnostics, event association |

Run `jupyter notebook` (or `jupyter lab`) from the project root after activating the virtual environment so relative paths to `../data` resolve correctly.
